Prefer to do it yourself? Follow the steps below.

What you need

  • 📱A phone with Chrome or SafariAndroid or iPhone. Use the browser, not an app, for the Meta and Cloudflare pages
  • 📸An Instagram professional account (Creator or Business), set to public
  • 👤A Facebook account you can log in toMeta needs it for the free developer app that gives the DM permission
  • 📧An email addressFor two free accounts you'll make in step 2: GitHub and Cloudflare
  • 👥A second Instagram accountA friend's or a spare one, to send the test comment
  • ⏱️About 40 minutes and a charged phone

💡 Turn on “Desktop site” when a page looks broken or a button is missing. Chrome: tap ⋮ → Desktop site. Safari: tap aA → Request Desktop Website.

🔒 Your Instagram token is like a password. You paste it in one place only: the Cloudflare form in step 4. Never in a chat, email or notes app.

Your progress0 of 6 done

  1. Change 3 settings in the Instagram app

    1. Professional account: Profile → ☰ → Settings and activity → Account type and tools → Switch to professional account → Creator or Business. Make sure the account is public.
    2. Allow DMs from tools: ☰ → Settings and activity → Messages and story replies → Message controls → Connected tools → Allow access to messages → On.
    3. Spam filter off: ☰ → Settings and activity → Hidden words → turn off “Hide comments” and “Advanced comment filtering”. Otherwise Instagram hides some comments and those people never get a DM.

  2. Make two free accounts

    Use the same email for both. Verify each email when it asks (check your inbox).

    1. GitHub: a free place to keep your own copy of the tool's code. The Deploy button in step 4 copies the code there for you.
    2. Cloudflare: it runs the tool online, every 5 minutes, for free.
    Sign up for GitHub ↗ Sign up for Cloudflare ↗

  3. Make your Meta app (in the browser)

    This is the longest step. Turn on Desktop site for these pages.

    1. Open developers.facebook.com/apps and log in with Facebook. First time? Tap Get started, accept and verify your phone or email.
    2. Tap Create App. Name it anything (like comment dm) and add your email.
    3. Use case: Manage messaging & content on Instagram. App type Business if it asks. If it asks for a business portfolio, pick or create one.
    4. In the app: Use cases → Customize (the Instagram one) → API setup with Unified login.
    5. Choose Instagram API (unified login) → Edit permissions. Keep only instagram_basic, instagram_manage_messages and instagram_manage_comments. Untick the rest and save.
    6. Under “Generate access tokens”, tap the blue Roles link → Add Instagram Testers → type your Instagram username → Submit.
    7. Accept the invite: open the link below (logged in to that Instagram account) → Tester Invites → Accept.
      instagram.com/accounts/manage_accessOpen
    8. Go back to the Meta tab and reload. Your account now shows with a number next to it (like 17841…). Long-press to copy it or write it down. That's your Instagram account number.

    📌 Keep this Meta tab open. You'll come back to it for the token in step 4. Don't tap Generate token yet.

    Meta renames buttons often. If something looks different, look for “Unified login” and “Generate access tokens”.

  4. Tap the Deploy button and fill 3 boxes

    You don't copy any code yourself. This button does it for you:

    1. It creates a new repo in your GitHub (named ig-comment-dm) and copies all the code into it: the auto-DM checker and the dashboard.
    2. It puts that code online on your Cloudflare account, so you get your own dashboard link.

    Afterwards you'll see this new repo in your GitHub. That's your copy. You never need to open or change it.

    Open the button in a new tab:

    Deploy to Cloudflare ↗
    1. Log in to Cloudflare if it asks.
    2. Tap Connect GitHub (or similar) → log in → Install & Authorize. This lets Cloudflare save your copy in your GitHub.
    3. Leave the names as they are. If it asks for a workers.dev name, type any name (like your username).
    4. Fill the 3 boxes:
      • IG_USER_ID: your account number from step 3.
      • DASH_PASSWORD: make up a new password for your dashboard (letters, numbers, dashes). Not your Instagram password. Write it down.
      • IG_TOKEN: switch to your Meta tab → tap Generate token → approve → tick the box → Copy. Switch back and paste it here.
    5. Tap the Deploy button at the bottom. Wait 2–3 minutes until it says it's done.

    🔒 The token box is the only place your token goes. Cloudflare stores it encrypted. Nobody, including whoever shared this guide, can see it.

  5. Open your dashboard

    1. On the finished Cloudflare page, tap your link. It looks like ig-comment-dm.yourname.workers.dev.
      Can't find it later? Cloudflare → Workers & Pages → ig-comment-dm → the link under Domains.
    2. Log in with any username and your dashboard password.
    3. Tap Run now. Your @username appears at the top. (If it says “Try again in a minute”, wait a minute.)
    4. Save it: Chrome ⋮ → Add to Home screen (Safari: Share → Add to Home Screen). Now it opens like an app.

  6. Add a keyword, test, go live

    1. Keyword rules → New rule → keyword AUTO (or pick Any emoji) → write the DM with your link → Save.
    2. Leave Dry run on. From your second Instagram account, comment AUTO on one of your posts.
    3. Within 5 minutes, Activity shows it as Dry run. Nothing was sent yet.
    4. Tap Go live, then comment again with a new comment. The second account gets the DM (check Requests if it doesn't follow you). 🎉

    Done. It now checks your comments every 5 minutes, day and night, with your phone on or off.

Good to know

How fast does the DM arrive?

Within 5 minutes of the comment, only for comments from the last 7 days. Each comment gets one DM, ever, so use a new comment for each test.

Someone says they got nothing

Ask them to check Requests in their DMs. Also make sure Hidden words → Hide comments is off (step 1). Instagram hides “spammy” comments from apps.

Dashboard says “Invalid OAuth access token”

The token is wrong. In Meta, tap Generate token again and copy it. Then in Cloudflare: Workers & Pages → ig-comment-dm → Settings → Variables and Secrets → edit IG_TOKEN → paste → Deploy.

I forgot my dashboard password

Set a new one the same way: Settings → Variables and Secrets → edit DASH_PASSWORD → Deploy.

The deploy failed

Open Workers & Pages → ig-comment-dm → Deployments (or Builds) and tap Retry. If the error says a name is taken, deploy again with a different name.

Is it really free and safe?

Yes. It runs on your own free Cloudflare account and uses Instagram's official API. You never share your Instagram password.
